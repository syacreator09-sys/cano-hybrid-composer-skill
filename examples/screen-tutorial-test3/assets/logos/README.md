# Logo Assets

CANO Screen Tutorial Mode supports official product/brand logos.

Preferred formats:
- SVG
- transparent PNG
- WebP

Use exact official assets when possible. Do not redraw a logo in CSS if a proper brand asset exists.

Suggested names:
- whatsapp.svg
- n8n.svg
- openai.svg
- hubspot.svg
- salesforce.svg

The tutorial engine can render logos using regular `<img>` elements, inline SVG, or data URIs.
